# Philosophy

The idea I stand by is simple:

> **You don't need to remember everything you've built to prove you know how to build it.**

If I create an amazing project today and forget how I made half of it a year from now, that doesn't make the achievement any less real. Before I started that project, I didn't know how to build it either.

The important part isn't memorising every function or every algorithm—it's knowing that I can sit down with an idea, experiment, fail a hundred times, and eventually figure it out. That's how every project I've made has happened.

To me, programming isn't about having all the answers.

It's about being confident that I can learn them.
